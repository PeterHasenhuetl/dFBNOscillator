# Analysis code of 'A half-center oscillator regulates sleep pressure'.

This is the MATLAB analysis code for two-photon imaging, patch-clamp recordings, and connectome analysis reported in 

"A half-center oscillator regulates sleep pressure" (2026) Nature Neuroscience, by Peter S. Hasenhuetl, Raffaele Sarnataro, Eleftheria Vrontou, H. Olof Rorsman, Clifford B. Talbot, Ruth Brain, and Gero Miesenböck

DOI of publication: https://doi.org/10.1038/s41593-026-02431-9

Each folder contains the scripts written for the experiments specified in the folder name. Short descriptions are in the top lines of the respective scripts.

These files also contain helper functions for plotting.
